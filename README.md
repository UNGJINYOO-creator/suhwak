# 수확중

한 문제는 씨앗 하나, 풀면 열매. 중등 수학 문제를 풀고 복습하는 안드로이드 앱이에요.
낚아보카(Wordbook) 앱의 구조를 그대로 가져와서 단어 대신 수학 문제로 바꿔 만들어요.

## 설치 · 업데이트
- 처음: GitHub 이 저장소의 Releases에서 최신 `Suhwak.apk`를 태블릿·휴대폰으로 받아 설치
- 그다음: 앱 설정의 업데이트에서 바로 받기 (새 빌드가 있으면 설정 탭에 빨간 점)
- `main`에 올리면 GitHub Actions가 테스트 → APK 빌드 → 릴리스(`Suhwak.apk` + `version.json`)까지 자동으로 한다.

## 계획
1. 뼈대: 낚아보카 코드를 수확중으로 이름·아이콘·업데이트 경로 변경 ← 지금
2. 씨앗(문제) 데이터: 문제집 쪽 → 씨앗 8개(문제·보기·정답·힌트·빈칸 풀이), 마클리 문제 은행 가져오기
3. 풀이 화면: 보기 버튼 · 입력 · 필기 · 수확하기 · 힌트(물 주기) · 빈칸 풀이
4. 복습: 간격 복습(물 주기 일정) · 오답 밭 · 찍기 방지
5. 재미: 오늘의 수확 · 열매 도감 · 농부 레벨 · 물뿌리개 도장판 · 단원 원정
6. 부모님: 텔레그램 리포트 · 주간 리포트 · 비밀번호 · 보상 쿠폰 · 가족 동기화(수확중용 Firebase)

## 구성
- Kotlin, Jetpack Compose(Material 3), Room, ML Kit
- 패키지 `com.suhwak.app`, 최소 Android 8.0
